# Security Policy

## Reporting vulnerabilities

Report security vulnerabilities privately through the FLDR repository:

https://github.com/digart11/FLDR/security/advisories

Include the FLDR version, Windows version, reproduction steps
and the potential security impact.

Do not publish sensitive vulnerability details, credentials
or personal files in public issues.

## Supported versions

Security fixes are intended for the current FLDR release.

## Scope

File operations, archive handling, previews, extension handling,
local configuration and Windows integration.
