# FLDR Edition Policy

FLDR is an unrestricted open-source application.

There are no commercial edition limits on profiles, connections,
batch operations, conversions or panes.

The legacy free Cargo feature and internal edition structures
are retained for source compatibility.

FLDR does not use commercial activation or entitlement refresh.

Application licensing remains AGPL-3.0-or-later.
Third-party components retain their respective licenses.

See LICENSE, NOTICE and legal/.
